# Data Sources and Schema Documentation

## 1. Primary Public Dataset

- **Name:** Brazilian E-Commerce Public Dataset by Olist
- **Source:** [Kaggle Dataset Page](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Publisher:** Olist (public dataset published by Olist)
- **Licence:** CC BY-NC-SA 4.0 (Attribution-NonCommercial-ShareAlike 4.0 International) / Kaggle Open Data Terms. *(Note: To comply with distribution terms, raw CSV files are not checked into this GitHub repository. Follow the download instructions below).*
- **Verification Date:** October 2024 / Local Verification 2026-10-17
- **Database Engine Used for Testing:** DuckDB (`data/olist.duckdb`)

---

## 2. Setup and Ingestion Instructions

1. Visit [Kaggle Olist E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) and sign in.
2. Download the dataset archive (`archive.zip`, ~42 MB compressed).
3. Unzip the CSV files directly into `data/raw/` (or run `python3 05-analytics/load_olist.py`).
4. Ensure `.gitignore` ignores `data/` and `archive/` so raw data files and DuckDB binaries remain local.
5. Ingest and inspect the tables using DuckDB:
   ```bash
   python3 05-analytics/load_olist.py
   ```

## 4. Key Data Characteristics & Observations

- **Order Status Distribution:**
  - `delivered`: 96,478 (97.0%)
  - `shipped`: 1,107
  - `canceled`: 625
  - `unavailable`: 609
  - `invoiced`: 314
  - `processing`: 301
  - `created`: 5
  - `approved`: 2
- **Repeat Customer Rate:**
  - Total customer records: 99,441
  - Unique individuals (`customer_unique_id`): 96,096
  - Transactions by repeat customers: 3,345 (~3.36%)
- **Payment Types Used:** Credit card, boleto, voucher, debit card.
- **Privacy & PII Considerations:** The public dataset contains no direct contact PII (no phone numbers, email addresses, or street names). Only city, state, zip code prefix, and anonymous UUIDs are present.
